# Vivaha Rani — Content raster system

Sistem konten memakai ivory-chikan sebagai dasar dan rani/sindoor, zardozi, paisley, marigold, serta daun mangga sebagai aksen modular. Semua aset berupa PNG raster; tidak ada SVG.

## Aset

- `page-background.png` — latar ivory tenang 1024×1536.
- `info-card.png` — kartu informasi transparan.
- `photo-frame.png` — bingkai foto paisley–zardozi transparan.
- `divider-paisley.png` — divider transparan.
- `section-marker-genda.png` — marker section transparan.
- `bottom-zardozi.png` — border penutup transparan dan opsional.
- `content-system-preview.png` — preview hierarki, bukan layer produksi.
- `source-renders/` — render sumber raster.

## Aturan

- Section teks: background + satu divider.
- Detail acara: background + info card + divider.
- Galeri: background + photo frame saja.
- Penutup: background + bottom zardozi; jangan tambahkan info card.
- Guest name, CTA, RSVP, hadiah dan peta memakai background paling tenang.
- Maksimal dua keluarga ornamen dominan per viewport.
- Jangan meletakkan paisley, marigold atau zardozi di belakang teks live.
- Jangan memakai simbol, tulisan atau benda sakral sebagai dekorasi interaktif.
