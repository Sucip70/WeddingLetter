# Vivaha Rani — Rani Toran gate

Gerbang raster untuk pernikahan Hindu India Utara kontemporer. Identitasnya memakai rani-pink, sindoor, zardozi, paisley/buta, marigold, daun mangga, ivory paper, serta chikan yang terkontrol.

Semua artwork produksi berupa PNG raster; tidak ada SVG. Teks hanya terdapat pada preview.

- `gate-background.png` — cover ivory-chikan yang terungkap.
- `left-panel.png` dan `right-panel.png` — panel sutra bergerak transparan.
- `interactive-genda-rosette.png` — objek tap dekoratif nonreligius.
- `closed-preview.png`, `opening-preview.png`, `reduced-motion-preview.png` — referensi state.
- `source-renders/` — sumber raster untuk penyuntingan.

Jangan menggunakan dewa, mantra, Om, swastika, kalash, diya, atau simbol sakral lain sebagai objek interaktif.
