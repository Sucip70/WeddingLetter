# Noor-e-Nikah — Content raster system

Sistem konten memakai ivory marble-paper sebagai dasar, kemudian jali, emerald enamel, antique gold, dan inlay Lahore sebagai aksen modular. Seluruh aset produksi berupa PNG raster; tidak ada SVG.

## Aset

- `page-background.png` — background ivory tenang 1024×1536.
- `info-card.png` — kartu transparan dengan crown cusped-arch.
- `photo-frame.png` — bingkai foto emerald–gold transparan.
- `divider-jali.png` — divider jali transparan.
- `section-marker-jali.png` — marker section transparan.
- `bottom-inlay.png` — aksen penutup pietra-dura transparan; opsional.
- `content-system-preview.png` — preview dengan teks contoh, bukan layer produksi.
- `source-renders/` — render sumber raster.

## Aturan penggunaan

- Halaman teks umum: background + satu divider.
- Akad/resepsi: background + info card + divider.
- Galeri: background + photo frame saja.
- Penutup: background + bottom inlay, tanpa info card.
- Peta, RSVP, hadiah, guest name, dan CTA memakai background paling tenang.
- Maksimal dua keluarga ornamen dominan dalam satu viewport.
- Jangan meletakkan jali, border emas, atau inlay di belakang teks live.
- Jangan memakai kaligrafi suci sebagai ornamen dekoratif atau elemen interaktif.
