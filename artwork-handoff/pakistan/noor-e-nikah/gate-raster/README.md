# Noor-e-Nikah — Jali of Noor gate

Gerbang raster untuk pernikahan Muslim Pakistan kontemporer dengan pengaruh craftsmanship Lahore. Identitas dibangun melalui ivory marble, emerald, antique gold, jali, serta aksen inlay yang terbatas—bukan ilustrasi istana atau masjid.

Semua artwork produksi berupa PNG raster. Tidak ada SVG. Teks pada preview hanya contoh; file produksi tidak berisi teks.

- `gate-background.png` — cover ivory yang terungkap setelah gerbang terbuka.
- `left-panel.png` dan `right-panel.png` — panel bergerak transparan.
- `interactive-jali-rosette.png` — objek tap nonreligius transparan.
- `closed-preview.png`, `opening-preview.png`, dan `reduced-motion-preview.png` — referensi keadaan.
- `source-renders/` — render sumber raster untuk penyuntingan lanjutan.

Jangan menjadikan kaligrafi suci, bulan sabit, atau elemen religius sebagai objek tap.
