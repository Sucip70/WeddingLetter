# Noor-e-Nikah Sample Photography

Natural opaque editorial pre-wedding sample photographs for the `noor-e-nikah` contemporary Pakistani Muslim invitation theme. The set uses a restrained, realistic Lahore heritage courtyard with soft natural light.

- `cover.webp` — full couple portrait, 2:3
- `groom.webp` — front-facing half-body groom portrait, 4:5
- `bride.webp` — front-facing half-body bride portrait, 4:5
- `gallery-romantic.webp` — romantic couple portrait, 4:5
- `gallery-walking.webp` — walking couple photograph, landscape

High-resolution PNG source files are retained in `sources/`.
